# ANNAM HOME

Первый интерактивный прототип сайта мебельного бренда ANNAM HOME.

## Локальный запуск

Из папки проекта:

```bash
python3 -m http.server 4180
```

Затем открыть `http://127.0.0.1:4180`.

## Статус данных

Коллекции, цены, материалы, условия производства и доставки пока являются демонстрационными. Перед коммерческим запуском их нужно заменить подтверждёнными данными.

## Подготовленные посадочные страницы

- `/modular-furniture/` — модульная мебель для дома.
- `/furniture-for-designers/` — дизайнеры и архитекторы.
- `/horeca-furniture/` — HoReCa и комплектация.
- `/oem-furniture-vietnam/` — OEM/ODM-производство мебели во Вьетнаме.
- `/furniture-logistics-vietnam-russia/` — логистика мебели Вьетнам ↔ Россия.

Все страницы подготовлены под отдельные группы запросов в SEO и Яндекс Директе. Перед публикацией необходимо:

1. Утвердить реальные условия, характеристики и контакты.
2. Подключить CRM или серверный обработчик форм.
3. Указать домен, добавить `sitemap.xml`, Метрику и цели.
4. Снять временный запрет индексации в `robots.txt`.
